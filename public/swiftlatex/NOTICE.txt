SwiftLaTeX browser engines

Upstream: https://github.com/SwiftLaTeX/SwiftLaTeX
Release: v20022022 (20-02-2022.zip)

The files in this directory are unmodified engine artifacts from the upstream
release. SwiftLaTeX is distributed under the GNU Affero General Public License
v3. See LICENSE.txt and the upstream repository for the corresponding source.

MDTeX loads these files as dedicated Web Workers. LaTeX source remains in the
browser. The workers fetch required TeX Live files on demand from the
Texlive-OnDemand endpoint configured by the MDTeX deployment.
